# KoCoSa 데이터셋 학습 전후 비교

klue/roberta-base를 KoCoSa 데이터셋으로 fine-tuning하기 **전**과 **후**의 비꼼 탐지 성능을 같은 데이터와 같은 지표로 비교한다. KoCoSa 논문([arXiv:2402.14428](https://arxiv.org/abs/2402.14428))의 결과와도 비교한다.

## 요약

| Test 셋 | BA | M-F1 | Acc |
|---|---|---|---|
| 학습 전 (klue/roberta-base 원본) | 50.0 | 32.5 | 48.3 |
| **학습 후 (KoCoSa fine-tuning)** | **72.8** | **72.5** | **75.1** |
| 변화 | **+22.8%p** | **+40.0%p** | **+26.8%p** |
| 참고: 논문 KLUE-RoBERTa-base | 74.0 | 74.1 | - |

- 학습 전 모델은 비꼼을 전혀 구분하지 못한다(BA 50.0 = 찍기 수준).
- 학습 후 BA 72.8로 올랐고, 논문의 같은 모델(74.0)과 비슷한 수준이다.
- 학습 후 모델은 Sarcasm 쪽으로 치우쳐서, 비꼼이 아닌 대화의 약 절반을 비꼼으로 판단한다.

## 실험 설정

### 데이터

Hugging Face `YuminKim/KoCoSa`의 분할을 그대로 사용했다.

| 분할 | 개수 | Sarcasm | Non-Sarcasm | 용도 |
|---|---|---|---|---|
| train | 10,466 | - | - | 학습 |
| validation | 1,321 | 801 (60.6%) | 520 (39.4%) | 학습 중 최고 모델 선택 |
| test | 1,037 | 570 (55.0%) | 467 (45.0%) | **최종 평가** (학습 중 한 번도 사용하지 않음) |

validation은 학습 중 최고 epoch를 고르는 데 썼기 때문에 성능이 약간 낙관적으로 나올 수 있다. 최종 성능은 **test 셋 기준**으로 판단한다.

입력은 학습 때와 같이 `context`(대화 맥락)와 `response`(응답)를 문장쌍으로 넣고, 최대 256 토큰으로 자른다.

### 비교 대상

| 이름 | 설명 |
|---|---|
| 다수 클래스 기준선 | 모든 입력을 Sarcasm으로 예측한다. 모델 없이도 나오는 최저 기준이다. |
| 학습 전 | klue/roberta-base 원본. 원본에는 비꼼 분류용 출력층(classifier)이 없어서 무작위로 초기화된다. 초기화 결과에 따라 달라지므로 seed 0, 1, 2로 3번 평가해 평균(±표준편차)을 냈다. |
| 학습 후 | KoCoSa train으로 full fine-tuning한 모델 (`model/`). 5 epoch 중 validation F1이 가장 높았던 2 epoch 체크포인트. 학습 설정은 [PROJECT.md](PROJECT.md#1단계-fine-tuning) 참고. |

### 지표

논문 Table 8과 같은 지표를 쓰고, 학습 코드에서 쓰던 지표(Acc, F1(S))를 함께 표시한다. 단위는 %다.

| 지표 | 의미 |
|---|---|
| BA (Balanced Accuracy) | 두 클래스 재현율의 평균. 클래스 비율이 달라도 찍기는 항상 50.0이 된다. |
| M-F1 (Macro-F1) | 두 클래스 F1의 단순 평균 |
| W-F1 (Weighted-F1) | 두 클래스 F1을 데이터 개수로 가중 평균 |
| Precision-S / Recall-S | Sarcasm으로 예측한 것 중 실제 Sarcasm 비율 / 실제 Sarcasm 중 맞힌 비율 |
| Precision-N / Recall-N | Non-Sarcasm에 대한 같은 값 |
| Acc | 전체 정확도 |
| F1(S) | Sarcasm을 양성으로 본 이진 F1 ([train.py](../scripts/train.py)에서 쓰던 지표) |

### 학습 후 모델의 혼동행렬 (Test)

| | 예측: Sarcasm | 예측: Non-Sarcasm | 합계 |
|---|---|---|---|
| **실제: Sarcasm** | 549 | 21 | 570 |
| **실제: Non-Sarcasm** | 237 | 230 | 467 |
| 합계 | 786 (75.8%) | 251 (24.2%) | 1,037 |

- 실제 비꼼 570개 중 549개(96.3%)를 맞혔다.
- 실제 비꼼이 아닌 467개 중 237개(50.7%)를 비꼼으로 잘못 판단했다.
- 데이터의 Sarcasm 비율은 55.0%인데 모델은 75.8%를 Sarcasm으로 예측한다.

## 해석

1. **학습 효과는 분명하다.** BA가 50.0에서 72.8로 22.8%p, M-F1이 32.5에서 72.5로 40.0%p 올랐다. 학습 전에는 비꼼을 구분하는 능력이 전혀 없었고, 학습으로 그 능력이 생겼다.
2. **F1(S)만 보면 학습 효과를 과소평가하게 된다.** 다수 클래스 기준선(전부 Sarcasm)도 F1(S) 70.9를 받는다. 학습 후 81.0과 비교하면 10.1%p 차이에 그친다. 클래스 불균형이 있는 데이터라서 BA, M-F1로 보는 것이 정확하다.
3. **Sarcasm 쪽 편향이 남아 있다.** Recall-S 96.3에 비해 Recall-N은 49.3이다. 학습 데이터에 비꼼이 더 많은 것이 원인일 수 있다. 개선 후보로는 클래스 가중치를 준 손실 함수, 분류 임계값 조정, 데이터 균형 맞추기가 있다.
4. **validation과 test 결과가 비슷하다** (BA 70.6 vs 72.8). validation으로 모델을 골랐지만 test에서 성능이 떨어지지 않아 과적합 우려는 크지 않다.

- **논문과 비슷한 수준으로 재현됐다.** 같은 KLUE-RoBERTa-base 기준으로 논문보다 BA 1.2%p, M-F1 1.6%p, W-F1 1.3%p 낮다.
- **차이는 Non-Sarcasm 재현율에서 가장 크다** (49.3 vs 54.7). 본 프로젝트 모델이 Sarcasm 쪽으로 더 치우쳐 있다.
- **크기가 훨씬 큰 범용 모델과도 비슷하다.** fine-tuning한 약 1.1억 파라미터 모델이 GPT-4 zero-shot(BA 73.2)과 비슷하고, GPT-3.5보다는 크게 앞선다.

### 비교의 한계

- 논문은 여러 번 학습한 평균(±)이고, 본 프로젝트는 한 번 학습한 결과(seed 42)다. 1%p 안팎의 차이는 학습 무작위성 범위 안일 수 있다.
- 논문의 학습 하이퍼파라미터(learning rate, epoch 등)는 본 프로젝트와 다를 수 있다.
- 논문은 데이터를 "약 8:1:1"로 나눴다고만 밝혔다. Hugging Face 데이터셋의 test 분할(1,037개)이 논문의 test 셋과 같은지는 확인하지 못했다.

## 재현 방법

```powershell
python scripts\baseline_eval.py
```

- validation과 test 모두 평가하고, 위와 같은 형식의 표를 출력한다.
- 결과는 [results/baseline_eval.json](../results/baseline_eval.json)에 저장된다. seed별 결과와 모든 지표가 들어 있다.
- 옵션: `--splits test`(test만), `--seeds 0 1 2 3 4`(seed 추가), `--batch-size 16`
- PC(CPU)에서 약 15분이 걸린다. klue/roberta-base 원본은 처음 실행할 때 Hugging Face에서 내려받는다(약 440MB).
